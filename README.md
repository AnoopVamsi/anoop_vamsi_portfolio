# Anoop Vamsi Meduri — AI/ML Portfolio

A premium, responsive personal portfolio for a Senior AI/ML Engineer specializing in Generative AI, RAG, agent evaluation, machine learning, and data engineering.

## Highlights

- Cinematic portrait-led hero with animated role titles
- Professional experience timeline
- Financial Document Intelligence and Agent Evaluation Lab case studies
- Interactive RAG architecture
- Dark and light themes
- Responsive layout and reduced-motion accessibility
- Centralized content in `app/data.ts`

## Technology

React, Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Build

```bash
npm run build
```

## Customize

Update personal information, links, experience, projects, and skills in `app/data.ts`. Replace `public/anoop-portrait.png` to change the hero image.
